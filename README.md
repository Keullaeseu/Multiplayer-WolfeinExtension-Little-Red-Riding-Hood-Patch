# Multiplayer Wolfein extension:"Little Red Riding Hood" Patch

A RimWorld Multiplayer compatibility patch for [Wolfein extension:"Little Red Riding Hood"](https://steamcommunity.com/sharedfiles/filedetails/?id=3698641606).

This mod is designed to improve multiplayer synchronization when playing with the [Wolfein extension:"Little Red Riding Hood"](https://steamcommunity.com/sharedfiles/filedetails/?id=3698641606) mod and RimWorld Multiplayer.

## Features

- Adds multiplayer compatibility for [Wolfein extension:"Little Red Riding Hood"](https://steamcommunity.com/sharedfiles/filedetails/?id=3698641606).

## Requirements

- RimWorld
- [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077)
- RimWorld Multiplayer
  - [GitHub version](https://github.com/rwmt/Multiplayer) or [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=2606448745) version
- [Wolfein extension:"Little Red Riding Hood"](https://steamcommunity.com/sharedfiles/filedetails/?id=3698641606)
- [Wolfein Race](https://steamcommunity.com/sharedfiles/filedetails/?id=3473140562) (Wolfein extension:"Little Red Riding Hood" dependency)
- [Multiplayer Wolfein Race Patch](https://github.com/Keullaeseu/Multiplayer-Wolfein-Race-Patch/releases/latest)
  — required: covers the Wolfein Race systems this extension builds on.
- [Wolfein Race Gene Patch](https://steamcommunity.com/sharedfiles/filedetails/?id=3473178683) (Wolfein extension:"Little Red Riding Hood" dependency, XML-only, no companion patch needed)
- [The Grand Library of 「Mirrored」](https://steamcommunity.com/sharedfiles/filedetails/?id=3782667656) (Wolfein extension:"Little Red Riding Hood" dependency)
- [Multiplayer The Grand Library of 「Mirrored」 Patch](https://github.com/Keullaeseu/Multiplayer-The-Grand-Library-of-Mirrored-Patch/releases/latest)
  — required: covers the story framework this extension is built on (dialogue option events, story progress, triggers).
- [Ancot Library](https://steamcommunity.com/sharedfiles/filedetails/?id=2988801276) (transitive dependency via Wolfein Race)
- [Multiplayer Ancot Library Patch](https://github.com/Keullaeseu/Multiplayer-Ancot-Library-Patch/releases/latest)
  — required: covers the Ancot Library base systems Wolfein builds on.
- [Humanoid Alien Races](https://steamcommunity.com/sharedfiles/filedetails/?id=839005762) (transitive dependency via Wolfein Race)
- [Multiplayer Humanoid Alien Races Patch](https://github.com/Keullaeseu/Multiplayer-Humanoid-Alien-Races-Patch/releases/latest)
  — required: covers the styling station and alien-comp appearance sync for HAR races including Wolfein.

The host and every connected player must use compatible versions of all required mods.

## Installation

### Steam Workshop

Subscribe to the required mods and add them to your RimWorld mod list in the following order:

1. Harmony
2. Core
3. Royalty, Ideology, Biotech, Anomaly, and Odyssey, if applicable
4. RimWorld Multiplayer
5. [Ancot Library](https://steamcommunity.com/sharedfiles/filedetails/?id=2988801276)
6. [Multiplayer Ancot Library Patch](https://github.com/Keullaeseu/Multiplayer-Ancot-Library-Patch/releases/latest)
7. [Humanoid Alien Races](https://steamcommunity.com/sharedfiles/filedetails/?id=839005762)
8. [Multiplayer Humanoid Alien Races Patch](https://github.com/Keullaeseu/Multiplayer-Humanoid-Alien-Races-Patch/releases/latest)
9. [Wolfein Race](https://steamcommunity.com/sharedfiles/filedetails/?id=3473140562)
10. [Multiplayer Wolfein Race Patch](https://github.com/Keullaeseu/Multiplayer-Wolfein-Race-Patch/releases/latest)
11. [Wolfein Race Gene Patch](https://steamcommunity.com/sharedfiles/filedetails/?id=3473178683)
12. [The Grand Library of 「Mirrored」](https://steamcommunity.com/sharedfiles/filedetails/?id=3782667656)
13. [Multiplayer The Grand Library of 「Mirrored」 Patch](https://github.com/Keullaeseu/Multiplayer-The-Grand-Library-of-Mirrored-Patch/releases/latest)
14. [Wolfein extension:"Little Red Riding Hood"](https://steamcommunity.com/sharedfiles/filedetails/?id=3698641606)
15. [Multiplayer Wolfein extension:"Little Red Riding Hood" Patch](https://github.com/Keullaeseu/Multiplayer-WolfeinExtension-Little-Red-Riding-Hood-Patch/releases/latest)

The patch should load after RimWorld Multiplayer, [Wolfein extension:"Little Red Riding Hood"](https://steamcommunity.com/sharedfiles/filedetails/?id=3698641606), and the companion patches listed above.

### Manual Installation

1. Download the latest release from the [**Releases**](https://github.com/Keullaeseu/Multiplayer-WolfeinExtension-Little-Red-Riding-Hood-Patch/releases/latest) section.
2. Extract the mod folder into your RimWorld `Mods` directory.
3. Enable the required mods in RimWorld.
4. Use the recommended load order listed above.
5. Make sure every multiplayer player has the same mod list, configuration, and load order.

## Multiplayer Usage

All players should have the following mods installed and enabled:

- RimWorld Multiplayer
- [Wolfein extension:"Little Red Riding Hood"](https://steamcommunity.com/sharedfiles/filedetails/?id=3698641606)
- [Multiplayer Wolfein extension:"Little Red Riding Hood" Patch](https://github.com/Keullaeseu/Multiplayer-WolfeinExtension-Little-Red-Riding-Hood-Patch/releases/latest)
- [Wolfein Race](https://steamcommunity.com/sharedfiles/filedetails/?id=3473140562)
- [Multiplayer Wolfein Race Patch](https://github.com/Keullaeseu/Multiplayer-Wolfein-Race-Patch/releases/latest)
- [The Grand Library of 「Mirrored」](https://steamcommunity.com/sharedfiles/filedetails/?id=3782667656)
- [Multiplayer The Grand Library of 「Mirrored」 Patch](https://github.com/Keullaeseu/Multiplayer-The-Grand-Library-of-Mirrored-Patch/releases/latest)
- [Ancot Library](https://steamcommunity.com/sharedfiles/filedetails/?id=2988801276)
- [Multiplayer Ancot Library Patch](https://github.com/Keullaeseu/Multiplayer-Ancot-Library-Patch/releases/latest)
- [Humanoid Alien Races](https://steamcommunity.com/sharedfiles/filedetails/?id=839005762)
- [Multiplayer Humanoid Alien Races Patch](https://github.com/Keullaeseu/Multiplayer-Humanoid-Alien-Races-Patch/releases/latest)
- All other required Wolfein extension:"Little Red Riding Hood" dependencies

The host and all connected clients should use the same:

- RimWorld version
- RimWorld Multiplayer version
- Wolfein extension:"Little Red Riding Hood" version
- Multiplayer Wolfein extension:"Little Red Riding Hood" Patch version
- Multiplayer Wolfein Race Patch version
- Multiplayer The Grand Library of 「Mirrored」 Patch version
- Multiplayer Ancot Library Patch version
- Multiplayer Humanoid Alien Races Patch version
- Mod configuration
- Mod load order

Do not add, remove, update, or reorder mods while players are connected to the same multiplayer session.

## Compatibility

This patch is intended to provide multiplayer compatibility for [Wolfein extension:"Little Red Riding Hood"](https://steamcommunity.com/sharedfiles/filedetails/?id=3698641606)
itself (dialogue-driven supply drops and goodwill, UAV submit actions, raid airstrike
dialog, homecoming letter choices, firearm ability reload orders, deterministic drone
wreckage and raid targeting).
Wolfein Race systems, the Mirrored story framework, Ancot Library base systems and
Humanoid Alien Races styling are covered by the required companion patches listed
above, not duplicated here.

It does not replace:

- [RimWorld Multiplayer](https://steamcommunity.com/sharedfiles/filedetails/?id=2606448745)
- [Wolfein extension:"Little Red Riding Hood"](https://steamcommunity.com/sharedfiles/filedetails/?id=3698641606)

## Known Limitations

- Compatibility may be affected by future RimWorld updates.
- Compatibility may be affected by future updates to RimWorld Multiplayer or Wolfein extension:"Little Red Riding Hood".
